Featured Projects

Featured
Optical pH Sensor for Hydroponic Systems

A complete end-to-end IoT system designed and built solo as a first-year university project (Ver 2.1). Combines custom EasyEDA PCB design, ESP32 firmware with a 12-state non-blocking FSM, dual-wavelength (6500K+3000K) Beer-Lambert HSV colorimetry, Dynamic Blanking, and a real-time WebSocket dashboard — all independently engineered.

C++ ESP32 PlatformIO WebSocket LittleFS EasyEDA (PCB) 3D CAD HTML/CSS/JS
Key Highlights
▸ 12-state non-blocking FSM automating 3-pump stack (fill, dose, mix, measure, R385 vacuum drain)
▸ Dynamic Blanking stage nulls background water discolouration before dye dosing
▸ Dual-wavelength optics (6500K+3000K LEDs) & HSV colorimetry with firmware validity gating
▸ Custom PCB (LM2596 buck, flyback-protected IRLZ44N MOSFETs) & 3D-printed flow cell

Airlock — Private AI Spreadsheet Analysis

Built for the OpenAI WebMCP Challenge: an AI agent that analyses your spreadsheet without ever receiving it. The CSV is parsed and computed over entirely inside the browser tab, and seven read-only WebMCP tools return only the aggregates the agent asks for — a default-on privacy mode that no tool can switch off. Unit tests cover every tool boundary.
